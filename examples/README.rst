Examples Guide
==============


This folder can host focused snippets that complement day modules.

Suggested Structure
-------------------

* ``examples/oop/`` for class design and polymorphism examples.
* ``examples/modern-cpp/`` for templates, ranges, and move semantics.
* ``examples/testing/`` for GoogleTest-focused examples.

Usage Pattern
-------------

* Keep each example minimal and runnable.
* Include one key takeaway at the top of each file.
* Add a matching test when behavior is non-trivial.
