Day 30: Review, Cert Prep, Next Steps
=====================================


Why This Day Matters
--------------------

This module builds practical skill in **Review, Cert Prep, Next Steps**, with emphasis on writing modern, maintainable C++ code.

Learning Outcomes
-----------------

* Explain the core ideas in your own words.
* Implement the day example and extend it safely.
* Identify tradeoffs and justify design choices.

Key Topics
----------

* knowledge consolidation
* topic gap analysis
* practice plan creation
* next-project planning

Hands-on Task
-------------

Build a 2-week follow-up plan based on weak-topic evidence.

Deliverable
-----------

A personalized continuation roadmap and revision checklist.

Suggested Workflow
------------------

#. Read ``theory.rst`` and summarize each concept in one sentence.
#. Run and inspect ``main.cpp`` behavior.
#. Review ``pitfalls.rst`` and apply one improvement.

Build and Run
-------------

.. code-block:: bash

    cmake -S . -B build -G Ninja
    cmake --build build --target day_30
    ./build/src/day_30
