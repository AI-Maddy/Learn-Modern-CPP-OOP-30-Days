# MkDocs Material Site for Learn-Modern-CPP-OOP-30-Days

## Features
- Material for MkDocs theme
- Custom color palette and icons
- Awesome Pages navigation
- Flashcard and mind map templates
- Cheatsheets and daily roadmap

## Getting Started

1. Activate the Python virtual environment:
   ```bash
   source /home/madhavan/projects/.venv/bin/activate
   ```
2. Install dependencies (already installed):
   ```bash
   pip install -r requirements.txt
   ```
3. Serve the site locally:
   ```bash
   mkdocs serve
   ```
4. Build the site:
   ```bash
   mkdocs build
   ```

## Structure
- `docs/` — Documentation content
- `overrides/` — Custom theme overrides
- `flashcard_template.md`, `mindmap_template.md` — Templates
- `mkdocs.yml` — Site configuration
