??? question "Motivation — Why SOLID?"
    SOLID is an acronym for five object-oriented design principles articulated by Robert C. Martin. They answer the question: "How do I structure my classes so the system stays easy to change, test, and extend over its lifet

??? question "Single Responsibility Principle (SRP)"
    A class should have only one reason to change.

??? question "Open/Closed Principle (OCP)"
    Software entities should be open for extension but closed for modification.

??? question "Liskov Substitution Principle (LSP)"
    Subtypes must be behaviourally substitutable for their base types.

??? question "Interface Segregation Principle (ISP)"
    Clients should not be forced to depend on interfaces they do not use.

??? question "Dependency Inversion Principle (DIP)"
    High-level modules should not depend on low-level modules. Both should depend on abstractions. Abstractions should not depend on details.
