## :material-head-question: Why This Exists in C++


??? question "❓ Why does C++ need Variables Types Constexpr?"
    Think about what problem this solves before reading the answer below.

    Choosing the right type and initialising it safely eliminates an entire category of runtime bugs before the program runs. The C++ type system is your most powerful tool for expressing invariants, and constexpr moves computation from runtime to compile time — free performance with no trade-off.

    _Continue to the [Definition page](02-definition.md) for the precise answer._
