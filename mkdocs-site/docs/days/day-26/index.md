!!! why-lobe "❓ Why This Day Matters"
    Game programming is one of the most demanding applications of C++ OOP. This day introduces four patterns used in professional game engines — ECS, fixed-step game loop, event bus, and CRTP — in a self-contained mini-project that you can run and extend. The patterns transfer directly to robotics, simulation, and real-time systems beyond games.
