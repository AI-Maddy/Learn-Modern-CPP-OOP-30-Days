!!! why-lobe "❓ Why This Day Matters"
    Inheritance is C++'s primary tool for expressing "is-a" relationships and enabling open-ended extension. Used correctly, it lets you write draw(shapes) once and have it work for every Shape subtype ever added. Used incorrectly, it produces slicing bugs, virtual destructor leaks, and fragile hierarchies. This day teaches you to tell the difference.
