30-Day Roadmap
==============


This roadmap complements the day folders in ``src/`` and helps with pacing.

Weekly Plan
-----------


Week 1 (Days 00-06): Foundations + Core OOP
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* Setup, type system, functions, class design, RAII, ownership, inheritance.
* Goal: become fluent with modern C++ fundamentals and OOP basics.

Week 2 (Days 07-13): Polymorphism + Generic Programming
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* Virtual interfaces, advanced OOP, templates, concepts, ranges, move semantics.
* Goal: write expressive and reusable C++ APIs.

Week 3 (Days 14-20): Robust Design + Testing
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* Rule of 5, error handling, modules mindset, patterns, SOLID, testing, CRTP.
* Goal: design stable code and validate behavior with tests.

Week 4 (Days 21-30): Advanced Topics + Projects + Review
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* PIMPL/type erasure, performance, C++26 preview, mini-projects, refactoring, review.
* Goal: consolidate skills and produce portfolio-grade exercises.

Daily Rhythm (Recommended)
--------------------------

* 20 min: read the day theory.
* 40 min: code through ``main.cpp`` and make one extension.
* 20 min: review pitfalls and write 1 test/assertion.
* 10 min: summarize what changed and why.

Completion Criteria
-------------------

* You can run all day executables.
* You can explain the key tradeoff for each topic.
* You can write at least one test for non-trivial logic.
* You can refactor confidently without breaking behavior.

Next Steps After Day 30
-----------------------

* Build one capstone integrating OOP + modern C++ features.
* Add CI quality gates (``clang-tidy``, sanitizer runs, coverage).
* Practice interview-style coding with your own examples.
